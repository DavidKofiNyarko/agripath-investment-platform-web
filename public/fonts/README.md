# Gilmer Medium Font

This directory should contain the Gilmer Medium font files.

## Required Font Files

Please add the following font files to this directory:

- `Gilmer-Medium.otf` (OpenType format - preferred)
- `Gilmer-Medium.woff2` (Web Open Font Format 2 - best compression)
- `Gilmer-Medium.woff` (Web Open Font Format - fallback)
- `Gilmer-Medium.ttf` (TrueType format - fallback)

## Where to Get the Font

The Gilmer font family can be purchased from:
- FontPath: https://www.fontpath.com/font/T9758/gilmer

## After Adding Font Files

Once you've added the font files to this directory, the app will automatically use Gilmer Medium throughout the entire application.

The font is configured in:
- `app/globals.css` - Font face declaration and global styles
- `app/layout.tsx` - Root layout font application
